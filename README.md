# WebAssistant

Easily deploy an AI assistant chatbot for your personal website.

This repository contains a Python library and the template for a React app, both of which use state-of-the-art Retrieval Augmented Generation (RAG) prompting methodologies.

## Prerequisites
1. Have the base URL of the website for which you want to create the chatbot
2. Choose a model backend:
	- OpenAI API key, or
	- Ollama running locally, optionally managed through Open WebUI

## Using (Just) Python

To use the python library, first install with

```bash
pip install WebAssistant
```

Then, write

```python
from WebAssistant import *
myChatbot = Hub()
myChatbot.launch(YOUR_OPENAI_API_KEY, YOUR_WEBSITE)
```

This will create a link to a chatbot built with Gradio that can answer questions about your website.

If you're looking for a very basic (and not recommended) solution, simply iframe the link on your webpage. Note that the link will expire every 3 days and will need to be regenerated using ``launch()``

## Using the React App
For a more flexible solution, run the following Python code. Make sure you have node installed first.

```python
from WebAssistant import *
myChatbot = Hub()
myChatbot.deployReactExpressApp(YOUR_OPENAI_API_KEY, YOUR_WEBSITE, YOUR_ROOT_DIRECTORY)
```

This will deploy a React frontend + Express backend to ``localhost:8080``. From there, you can upload it to Cloudflare, Render.com, Fly.io, Railway, or other providers, and then iframe the link generated by those sites inside a dedicated container in your website for the chatbot.

Note that you must NOT remove the credits to this repository included at the bottom of the chatbot UI.

## Ollama + Open WebUI (Node backend)

The Express backend now supports both OpenAI and Ollama. Default provider is Ollama.

### Recommended local setup

1. Start Ollama and pull models:

```bash
ollama pull llama3.1:8b
ollama pull nomic-embed-text
```

2. (Optional) Start Open WebUI and connect it to Ollama.

3. In `AppTemplate/server/.env`, set:

```env
URL="https://your-site.com"
LLM_PROVIDER="ollama"
OPEN_WEBUI_URL="http://localhost:3000"
OLLAMA_MODEL="llama3.1:8b"
OLLAMA_EMBEDDING_MODEL="nomic-embed-text"
```

If `OPEN_WEBUI_URL` is set and `OLLAMA_BASE_URL` is not set, the server automatically uses `OPEN_WEBUI_URL/ollama`.

If you want direct Ollama (without Open WebUI), set:

```env
LLM_PROVIDER="ollama"
OLLAMA_BASE_URL="http://127.0.0.1:11434"
```

If you want OpenAI instead, set:

```env
LLM_PROVIDER="openai"
OPENAI_API_KEY="your-key"
OPENAI_MODEL="gpt-4o"
OPENAI_EMBEDDING_MODEL="text-embedding-3-small"
```

## Embeddable Widget For Any Website

This template now supports a drop-in embed script that creates a floating chat launcher and widget panel.

### 1) Deploy the app

Deploy the client and server so they are reachable at your assistant base URL (example: `https://assistant.example.com`).

### 2) Paste this on the target website

```html
<script
	src="https://assistant.example.com/embed.js"
	data-title="Ask our AI"
	data-site-url="https://designer-site.example.com"
></script>
```

`data-site-url` is optional. If omitted, the script uses the current website origin automatically.

### 3) Optional data attributes

- `data-title`: Label on the launcher button. Default is `Ask AI`.
- `data-site-url`: The website URL that should be indexed for answers.
- `data-assistant-base`: Override assistant base URL if the script is proxied.
- `data-z-index`: Layer priority for overlapping UI.

The embedded iframe opens with `?embed=1&siteUrl=...`, and the client sends both the site URL and current page URL to `/api/respond`. The server caches one RAG session per site URL in memory.
